import pandas as pd
import altair as alt

url = "https://cdn.jsdelivr.net/npm/vega-datasets@2.8.1/data/obesity.json"
obesity = pd.read_json(url)
from vega_datasets import data as vega_data
us_states = alt.topo_feature(vega_data.us_10m.url, 'states')

chart = alt.Chart(us_states).mark_geoshape(
    stroke='white'
).properties(
    width=800,
    height=500,
    title="Obesity Rates Across US States"
).project('albersUsa')

chart += chart.encode(
    color=alt.Color('rate:Q', scale=alt.Scale(scheme='blueorange'), title='Rate'),
    tooltip=['state:N', 'rate:Q']
).transform_lookup(
    lookup='id',
    from_=alt.LookupData(obesity, 'id', ['rate', 'state'])
).project('albersUsa')

chart

Choices

The reason I choose a choropleth map is because, when I saw the data, I want to visualize a data that shows the obesity rates across US states. I chooses the blue orange scheme for this because it is is a high-contrast color scheme that is easily distinguishable for most people and it also provides a clear visual indication of increasing or decreasing values. In addition to this, I also added a legend to provide clarity for the audience to understand the reasoning behind the colors used in the map. Lastly, I added interact option so that it is easy for audience to hover over the states to see the rates and the state abbreviations.

I think an alternative thing that I thought I can do is to add a interactive to just highlight one state at a time to change the focus.
